I want to have an app that is a digital equivalent of pocket notebook where i can jot down whatever comes to my mind on that go.

There are primarily two things that i want to jot down. Tasks that i would want to do, and any idea / note that is not a task.

the notes part of the app should do the following:
- i should be able to add note by both typing and by voice input.
- the notes should be bare minimum, no title etc, just the note. I want it to be minimal.
- default view should be to view all the notes for the current day.
- There should be a provision of view the notes by day, week and month.

The todos part of the app should do that followin
- i should be able to add, edit, delete a todo
- i should be able to mark a todo complete.
- todo need not have a title, as i want it to be minimal. It should just have some text.
- i should be able to schedula a todo, date and time. 
- I should be able to setup todo that are repeats ( daily, weekdays, weekends, particular days of week, monthly, annually ( like birthdays and anniversaries))
- i should be able to view all the open tasks, also all tasks by day, week, month, year


we can do that app in two phases, first the notetaker, and then the todo list.

I will be using this app primarily from my phone ( android ). However, I should also be able to view these from the web. I am planning to deploy this on my android phone via google play.
