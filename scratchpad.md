# Scratchpad — Pocket Notebook dev notes

Practical commands for building, deploying, and running the app on the Android
emulator. Verified working on the current laptop (2026-09-02).

## Environment (set these in every build/run shell)

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64   # JDK 17 REQUIRED (default `java` is 21)
export ANDROID_HOME=$HOME/Android/Sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH
```

Verify: `javac -version` must print **17** (not 21/25 — AGP rejects those).

## Required toolchain (RN 0.86.2 / Expo ~57)

Versions come from `node_modules/react-native/gradle/libs.versions.toml` — re-check after any RN bump.

| Component      | Version          | Install |
|----------------|------------------|---------|
| JDK            | 17               | `sudo apt install openjdk-17-jdk` |
| NDK            | `27.1.12297006`  | `sdkmanager "ndk;27.1.12297006"` |
| CMake          | `3.22.1`         | `sdkmanager "cmake;3.22.1"` (a newer cmake alone is NOT enough) |
| Platform       | `android-36`     | `sdkmanager "platforms;android-36"` (compileSdk/targetSdk = 36) |
| Build tools    | `36.0.0`         | `sdkmanager "build-tools;36.0.0"` |

`sdkmanager` lives at `$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager`.
Accept licenses once: `yes | sdkmanager --licenses`.

## One-time / fresh-machine setup

```bash
npm install
npx expo prebuild --platform android          # generates the gitignored android/ project
echo "sdk.dir=$ANDROID_HOME" > android/local.properties
```

## Build the debug APK

```bash
cd android && ./gradlew :app:assembleDebug     # ~8 min first run
# output: android/app/build/outputs/apk/debug/app-debug.apk (~219 MB)
```

## Run in the emulator

`adb: no devices/emulators found` just means nothing is running yet — start the emulator (or plug in a phone) FIRST.

```bash
# 1. list AVDs, then boot one (we have "Pixel_10_Pro")
emulator -list-avds
emulator -avd Pixel_10_Pro -gpu auto &
adb wait-for-device
# wait until fully booted:
until [ "$(adb shell getprop sys.boot_completed | tr -d '\r')" = "1" ]; do sleep 2; done

# 2. install the APK + launch, with Metro for the JS bundle (debug build loads JS from Metro)
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb reverse tcp:8081 tcp:8081
npx expo start --dev-client &                   # Metro on http://localhost:8081
adb shell monkey -p com.pocketnotebook.app -c android.intent.category.LAUNCHER 1
```

App package id: **`com.pocketnotebook.app`** (MainActivity).

## Handy adb / debugging

```bash
adb devices -l                                  # list connected devices
adb kill-server && adb start-server             # fix a stuck adb
adb exec-out screencap -p > shot.png            # screenshot the emulator
adb shell dumpsys activity activities | grep -i ResumedActivity   # what's in foreground
adb uninstall com.pocketnotebook.app            # clean reinstall
pkill -f 'expo start'                            # stop Metro
```

## Notes / gotchas

- Deploy in Android Studio by opening the **`android/`** folder (not the repo root).
- `android/` and `android/local.properties` are gitignored (regenerated by prebuild).
- To iterate on JS only, no rebuild needed — keep Metro running and edit `src/`.
- This laptop has 31 GB RAM, so the emulator + Gradle can run together (the old box could not).
